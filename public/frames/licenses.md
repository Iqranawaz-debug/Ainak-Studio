# Licenses for the More styles frames

Every file below was exported from the original SVG on its source page, then trimmed, centered and resized to 1000px wide. Those original SVGs are kept unchanged in public/frames/svg/, under the same licenses, and the 3D frames are extruded from them.

Licenses were checked on 2026-11-03. Each source page links to Openclipart's license page (https://openclipart.org/share), which states that all Openclipart images are released under CC0 1.0. This is a site-wide statement, not a statement written for each individual file.
